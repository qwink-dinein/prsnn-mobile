## What's in this version

**Members**
- Phone sign-in on WhatsApp (SMS backup); email for visitors from abroad; PIN unlock.
- Photo open by default; choosing "Locked" first shows "Public photos get more bookings".
- Search with city, area, category and sort; **Available today** switch (free for the rest of today, with hours);
  visible photos rank first.
- Tap a photo to open it large (View profile / Book).
- Book on the companion's page (length, day, time; no double booking), pay with Razorpay, chat from confirmation
  until the session ends, panic button, cancel and refunds by the rules.
- "Become a companion" card on Home with what you keep (80%) and the four steps; also on Welcome and prsnn.com.

**Companions**
- Booking | Companion modes on one account; requests, earnings, client chats in Companion mode.
- ID check at first booking; once ID verified, never asked again. "ID verified" only after a real check.
- WhatsApp alert for every new paid booking (and when a booking is confirmed for them).

**Staff**
- Staff is a permission on top of a member / companion account: Admin | Booking | Companion switch.
- Admin: approvals, ID checks, bookings, refunds (failed ones visible), disputes, panic alerts, people and money
  counts (real payments only), prices, broadcasts, sub-admins, activity log, live preview of any member or companion.

**Payments and messages**
- Prices 399 / 699 / 999 / 1,299 … 3,599; companion keeps 80%; 15% fee for late cancellations.
- Razorpay webhook with a new secret; duplicate payments refunded automatically; refunds only count once Razorpay confirms.
- WhatsApp messages count as sent only on Waplify success; failures are logged with the reason.

## Getting back to this version

On the Mac (app):
```
cd ~/prsnn-mobile && git fetch --tags && git checkout stable-2026-11-18
npm install
npx eas-cli@latest build -p android --profile preview --local --output ~/prsnn-builds/prsnn-stable-2026-11-18.apk
```
(`git checkout claude/adoring-euler-w8jj3h` goes back to the latest work.)

Website: Cloudflare builds from the branch; to republish this version, ask Claude to reset the branch to the tag.

Database: the migrations in `prsnn-backend/supabase/migrations` up to `20261118140000` rebuild the schema; the
snapshot file lists what was live. Data (users, bookings) is not in git: turn on Supabase backups (Pro plan) for that.
